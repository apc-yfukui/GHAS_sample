脆弱なAI十徳ナイフ (Vulnerable AI Swiss-Knife)

A. AI Prompt Injection / LLM01

ユーザー入力をAIプロンプトに結合して要約を生成します。

B. SSRF / A01:2025 Broken Access Control

指定したURLのドキュメントを読み込みます。

C. Cross-Site Scripting / A05:2025 Injection (XSS)

AIの回答（Markdown）をプレビューします。

D. Path Traversal / A01:2025 Broken Access Control

ファイル名を指定してダウンロードします（例: ../../etc/passwd）。

E. SQL Injection / A05:2025 Injection

ユーザー名でユーザー検索します（例: ' OR '1'='1）。

F. Weak Cryptography / A04:2025 Cryptographic Failures

MD5でパスワードをハッシュして登録します（破られた暗号アルゴリズム）。
